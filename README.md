# GRT Enterprise Portfolio — English V2

A redesigned Flask website for the Scuderia GRT T18 Enterprise Portfolio.

## Key changes from the previous version
- Entire interface is in English.
- Supplied GRT logo is used as the single logo in the top-left corner.
- No separate GRT wordmark is repeated in the navigation.
- Official Instagram handle shown as `@scuderiagrt`.
- Clicking the handle opens the Instagram profile in a new tab.
- More graphical dashboards, KPI cards, radar-style sustainability graphic,
  sponsorship tier visualization, ROI panel, pit drawing, timelines and checklists.
- Real figures from the supplied portfolio are displayed.
- Unsupported / missing figures are explicitly marked for verification.
